# The System You're Actually Living In

Author: Daniel Rader <Daniel.rader150@icloud.com>

This repository contains a single-page static site explaining debt-based money. The public site is published via GitHub Pages at:

https://drader150.github.io/The-Debt-Based-Monetary-System-for-Everyday-People/

Private update instructions (for repository owner / collaborators):

- Edit index.html locally (or on a feature branch).
- Commit your changes to the branch "drader150-publish-website":

  git checkout drader150-publish-website
  git add index.html
  git commit -m "Your message"
  git push origin drader150-publish-website

- The repository has a GitHub Actions workflow that will automatically deploy the branch to the gh-pages branch and publish the site.

Notes:
- Visitors cannot edit the live site; only repository collaborators with push access can update content.
- If you want staged reviews before publishing, use a different branch and open a pull request against drader150-publish-website instead.
